## 08-core-api-list.md

### 高

- **L75** [技术错误] 「栈约束: `stack_size ≥ TG_STACK_MIN`(2K [?]), **8 字节对齐**; 栈 guard = vx(红区)」
  - D9 已定 aarch64 为唯一 ISA。AAPCS64 要求 SP 在函数边界 **16 字节对齐**；仅 8 字节对齐的线程栈可构造出 8 mod 16 的初始 SP，违反 ABI（编译器按 16 字节假设生成 `stp/ldp`，可致对齐异常；FreeRTOS/Zephyr 的 arm64 口均要求 16）。属会直接进实现的硬技术错误。
  - 建议: 改「初始 SP 16 字节对齐（栈大小为 16 的倍数）」。

### 中

- **L26** [前后矛盾] 「| `tg-mm.txt` | MMU/cache(§7) | 5 | 无 | 第一批(**签名 M2 起冻结**, R4) |」

  - 建议: 统一 D15 口径（M3/v1.0 升格 frozen）；「设计定稿」换词。
- **L61/L63/L64** [前后矛盾] 「core 构造 + `sched_ops.create` / core + `sched_ops.switch_out` / `sched_ops.yield`」
  - 主文档 §5.1 `tg_sched_ops` 已列槽位为 thread_ready/thread_block/pick_next/on_tick/thread_sleep/mutex_*/sem_take，**没有**这三个名字（「交调度器入列」对应 `thread_ready`）；10-sched 全字段表未成文，属无出处的前向引用。
  - 建议: 改用主文档已有槽位名，或标注「槽位名待 10-sched 定稿」。
- **L65/L66** [技术错误] 「`tg_task_sleep` | … | `-EINVAL`(**负值**) | …」

  - 建议: 删「负值」，改「TG_TIMEOUT_INF → -EINVAL」（或另行定义 INF 语义）。
- **L72** [技术错误] 「线程状态机(core 拥有): `NEW → READY ⇄ RUNNING → BLOCKED(等待队列+超时表) → ZOMBIE →(join 回收)`」
  - 缺 **BLOCKED→READY**（唤醒）迁移；**BLOCKED→ZOMBIE** 与 L46「`tg_task_exit` 只能结束自身」（仅运行态可调）矛盾，缺 RUNNING→ZOMBIE。
  - 建议: 补齐三条迁移（BLOCKED→READY、RUNNING→ZOMBIE、RUNNING→READY 已由 ⇄ 覆盖）。
- **L24/L374** [前后矛盾] 「第二批(M3 后, conformance 矩阵压测后): `tg-sched`——…必须 `{sched-coop, sched-preempt, sched-tt} × 同一套语义测试` 全绿后升格」

  - 建议: 明示「第二批实际时点 ≥ v3.0」或放宽为「已有调度器矩阵」（coop-only 先行）。
- **L262** [格式引用] 「类型契约由服务方文档化(`docs/6-vfs-device/04-vfs.md` §0.1 消费者表即用法总览)」
  - 04-vfs.md **无 §0.1**（章节为 §1–§7）；「消费者的依赖声明」表实际在 **06-device.md §1**。
  - 建议: 改引 `06-device.md` §1。
- **L284** [前后矛盾] 「`TG_TRACE_EVT` 宏(`docs/4-debug/03-debug.md` §1) | 中断内追踪」
  - 被引 03-debug §1 定义的宏名是 **TRACE_EVT**（无 TG_ 前缀），与 D16「宏 `TG_*`」规范冲突，一宏两名对不上。

## 总体评价

os-core 模块文档技术底子扎实: ISR/bh 双上下文契约、级联中断域 FAST/SLOW 模型、内存三池、锁对象「core 公共头 + 调度插件私有尾」等设计符合嵌入式内核常识，与主文档 D1–D23 决策骨架大体自洽，**未发现成体系的胡言乱语**。主要质量风险集中在两点: 一是少量**硬性技术错误**（aarch64 栈 8 字节对齐、无符号参数报「负值」、线程状态机缺迁移）；二是系统性的**跨文档漂移**——冻结时机三种口径、调度 ops 槽位名、链接段名、trace/inline 宏名、以及 4 处断裂引用（04-vfs §0.1、「06 §8」、「§9 的 PRE_ARCH」、roadmap DoD 编号），表明 08 成文之后主文档与各骨架文档未做一轮一致性回写。建议以 08 + 主文档为真值做一次专门的对表修订，并在术语上区分「设计定稿」与「升格 frozen」。

**问题统计: 高 1 / 中 19 / 低 15，共 35 条**（subagent 原报 32 条: 高 1/中 17/低 14；主评审上调 1 条（08 L289 SD-10）、补充 3 条（08 L170、10-sched L12、08 L338 `__start_` 编译问题））。
